## 1. Objetivo de la reunión

Revisar el caso de estudio inicial del proyecto y determinar los cambios necesarios para que permita identificar de manera clara las entidades, atributos, relaciones, cardinalidades y reglas de negocio requeridas para la construcción del modelo entidad-relación.

## 2. Agenda

1. Revisión del caso de estudio inicial.
2. Identificación de ambigüedades.
3. Definición de ajustes necesarios.
4. Distribución de actividades para la reformulación del caso.

## 3. Desarrollo de la reunión

Durante la reunión se revisó el caso de estudio inicial y se identificó que la información presentada no permitía determinar de manera suficientemente explícita las entidades y relaciones del sistema.

Se observó que algunas partes del caso mezclaban reglas de negocio con decisiones propias del modelado, lo que generaba ambigüedad al momento de identificar las entidades, relaciones, cardinalidades y restricciones.

Como resultado, el equipo decidió replantear el caso de estudio desde cero, utilizando los conocimientos adquiridos sobre modelado entidad-relación.

También se estableció que el nuevo caso debía expresar de forma clara las cardinalidades y la opcionalidad de las relaciones, evitando dejar decisiones importantes implícitas.

## 4. Dificultades identificadas

* El caso inicial no describía claramente todas las entidades involucradas.
* Algunas relaciones no permitían determinar fácilmente sus cardinalidades.
* Existía una mezcla entre reglas del negocio y decisiones de modelado.
* Fue necesario reorganizar la información antes de continuar con el modelo entidad-relación.
